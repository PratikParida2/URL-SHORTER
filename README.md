# URL Shortener with Authentication

A URL Shortener web application built with **Node.js**, **Express**, **MongoDB**, and **React**. The app allows users to shorten long URLs, redirect to the original link, and manage their shortened URLs. It includes **authentication** using **JWT** and **cookies** to manage user sessions.

## 🚀 Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express
- **Authentication**: JWT, Cookies
- **Database**: MongoDB (using Mongoose)

## 🔧 Features

- **User Authentication**: Register and login with JWT authentication
- **Shorten URLs**: Logged-in users can shorten URLs
- **Cookies**: JWT stored in cookies for session management
- **Redirect**: Shortened URLs redirect to the original link
