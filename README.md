# URL Shortener

A simple URL shortener web application built with **Node.js**, **Express**, **MongoDB**, and **React**. This app allows users to shorten long URLs and redirect to the original link using a short, unique ID.

## 🚀 Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB (using Mongoose)

## 🔧 Features

- Shorten long URLs
- Redirect to original URLs via shortened links
- Store URLs in a MongoDB database
